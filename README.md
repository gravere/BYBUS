BYBUS 让你在安卓手机和平板上使用中文游玩《边狱巴士》。默认使用[都市零协会](https://github.com/LocalizeLimbusCompany/LocalizeLimbusCompany)汉化，也支持导入自己的汉化包，或接入自己的 API 按需翻译。

**先安装官方《边狱巴士》，不用打开原版，直接打开 BYBUS 跟着提示操作即可。** 汉化准备、游戏登录和首次资源下载都从 BYBUS 完成，以后也从 BYBUS 启动游戏。

## 功能特点

- **汉化由你选择** — 导入后检查覆盖，可让零协补齐空缺、选择 AI 补译，或保持原样。支持多个来源、名称与图标管理，也能备份文本和通过链接更新。
- **AI 补译，也能从零翻译** — 接入自己的 API，补充现有汉化，或直接按游戏原文分批生成。可分类查看译文，单条或多选重译、删除，自定义提示词，按需翻译或连续处理整个范围。
- **装好原版，直接开始** — 免 Root，无需修改游戏安装包。进入游戏前准备汉化，首次下载资源后即可加载已有译文，不用退出重进。
- **无需绑定加速器** — 自备能访问游戏及相关服务的网络即可使用，无需开通特定加速器会员。BYBUS 本身不提供网络加速。
- **换机也能带走资源** — 游戏资源可导出、迁入，接收设备只需由游戏补齐缺少的内容；汉化包也可单独备份。
- **更新、修复集中管理** — 应用更新红点提醒、增量下载、原版更新入口与汉化修复集中在设置中，手机和平板均有对应布局。

## 开始使用

准备一台 **Android 8.0 及以上的安卓手机或平板**，先确认能安装官方原版游戏。使用时需要能访问游戏服务器、GitHub 和所用登录服务（如 Google）的网络；详细设备条件见[适配说明](docs/android-runtime-portability.md)。

1. **安装原版游戏** — 在设备上安装官方《边狱巴士》。安装完成后不用打开它，也不用在原版里下载资源。
2. **安装并打开 BYBUS** — [下载完整 APK](https://github.com/gravere/BYBUS/releases/latest/download/BYBUS-Android.apk) 并安装，打开后按首页提示操作。
3. **进入游戏** — BYBUS 会识别原版、准备汉化并启动游戏。在这个游戏窗口中登录账号、完成首次资源下载，即可游玩。
4. **以后直接从 BYBUS 启动** — 保留已安装的原版；官方发布新版本时按[更新说明](#更新与维护)操作。BYBUS 会按所选汉化源准备资源，默认零协汉化在启动前自动检查更新。

> [!NOTE]
> 按以上步骤，大型游戏资源只需在 BYBUS 中下载一遍。如果你以前已在原版游玩，原版的资源与登录状态不会自动带入 BYBUS；已有兼容资源包可通过[数据迁移](#资源备份与迁移)导入。

使用 Google 登录时，可以直接在游戏登录界面选择 Google，按提示添加或选择账号；也可以提前在「设置与工具 → Google 账号与付款」中添加。手机系统里已登录的 Google 账号不会自动出现在 BYBUS 中，需要在 BYBUS 里添加一次，可以使用同一个账号。商店与付款服务默认开启。

使用 Apple 账号时，在游戏登录界面选择 Apple，在授权窗口完成登录后返回游戏；不需要在 BYBUS 的 Google 设置中添加 Apple 账号。

游戏运行时，点桌面 BYBUS 图标会返回游戏。要换汉化或调整设置，长按桌面图标，选择 **管理 BYBUS**，即可打开启动器首页。首页任务按钮可返回正在进行的检查、翻译或其他任务。

## 选择汉化与 AI 翻译

打开「**设置与工具 → 汉化 → 汉化源与更新**」，或点击首页运行状态中的汉化一栏。

| 来源 | 使用方式 |
| --- | --- |
| 都市零协会 | 默认来源，启动前自动检查正式汉化包，也可手动检查更新 |
| 本地汉化包 | 导入兼容的 ZIP / 7z 文本包，自选补齐方式；可替换文件或添加下载链接更新 |
| AI 翻译 | 配置自己的 API 地址、模型和 Key，补充当前包，或选择「从零全局翻译」生成新包 |

包名下方会显示本地包的添加时间、AI 包的生成时间，或零协包在本机的下载时间。在「管理当前汉化源」可更换图标、导出汉化包，本地与 AI 来源还可改名、替换或删除。切换后，下次启动使用所选来源。基于零协补译的 AI 包可检查零协更新，由你决定是否同步；全局 AI 包独立保存在本地。

**导入后，决定空缺怎么处理。** BYBUS 会按当前游戏语言检查已下载的文本，提供「零协补齐」「选择 AI 补译范围」「保持原样」。零协只填空缺，保留导入包已有的译文；AI 会先进入范围与费用确认，不会自动开始翻译。还没下载游戏文本时，会提示暂时无法检查，之后可从「补齐未覆盖文本」重新操作。零协补齐后可随时「恢复导入原包」。

**自定义包也能自动更新。** 在「导入包设置 → 添加更新链接」填写 HTTPS ZIP/7z 下载直链；GitHub Releases 可使用 `releases/latest/download/文件名` 形式。开启后，启动游戏前每小时最多检查一次，也可随时手动检查；有新内容会自动下载并校验，再替换当前包。原有的名称、图标和零协补齐选择会保留，下载或校验失败时继续使用旧包。普通网页链接不能代替文件下载链接。

首页下方卡片默认跟随当前汉化源，也可通过卡片右上角菜单固定显示某个来源。这个选择只改变卡片展示，不改变游戏使用的汉化。点击都市零协会右侧的项目按钮，可查看 GitHub 更新和翻译进度。

AI 翻译处理已下载的游戏文本，测试和翻译会使用你自己的 API 额度；只有你明确开始翻译或选择补译后启动时才会调用 API。已完成的译文会保留，结果单独保存，不覆盖零协原包。API Key 在设备上加密保存，不随诊断或备份导出。

**从零翻译无需现成汉化包。** 在 AI 页面选择「从零全局翻译」，读取游戏原文后选择类别或条目。尚未下载原文时，可从这里进入游戏下载资源，再返回生成。数量选择「全部」可连续处理所选范围，支持十万条以上的任务；随时暂停，之后接着翻译。

首页的 AI 卡片显示实际 AI 已译条数，点击即可分类查看原文和译文，支持单条或多选重译、删除。每次开始前都能选择密钥、模型、提示词和本次条数。删除仅移除选中的 AI 译文，没有其他译文时会显示游戏原文。

汉化源列表与 AI 页面都按原始汉化包折叠展示各个版本，子项显示语言、生成时间和已译条数。新包按原包与游戏语言命名，重名时自动加数字；继续同一包会保留名称。

**原包更新，无需重译全部。** 打开 AI 包的「检查原包更新」，查看新增、改写的译文，选择后合并。选中的内容采用原包译文，即使文字与 AI 相同也归回原包；其余 AI 译文保留，可撤回本次改动。全局 AI 包没有依托的原包，无需此步骤。

**用量和费用看得见。** 翻译任务显示接口返回的输入／输出 Token、耗时和参考费用。模型价格从 [Models.dev](https://models.dev) 同步；可按模型名、ID 或服务商搜索并选择参考价，也可手动填写单价和币种。选价不会更换翻译模型。费用是估算，实际以服务商账单为准；没有用量或价格时会明确显示未知。

**公告单独翻译。** 先在游戏内打开公告，再刷新 AI 翻译条目，在「公告与邮件」中选择标题或正文。整篇正文准备好后才替换，链接和格式保留；没有对应译文的标题或正文保持原文。

翻译中可离开页面，从首页的任务按钮返回；暂停或关闭应用后也能继续。如果暂停时替换了汉化包，任务结果会另存，当前文件不会被覆盖。取消任务只删除本次尚未发布的译文。

填写服务地址后，可点「获取模型」读取上游列表、搜索并选择模型，也可直接手填模型 ID。支持匿名列表的服务无需先填 Key；需要授权的服务会提示填写。获取列表不会开始翻译。

可以保存多把密钥，在「切换密钥」中选择、改名或删除；长按右侧手柄即可拖动排序。

在汉化源或 AI 翻译页面查看「汉化覆盖」，可按类别对照原文和现有译文，再选择处理「未覆盖」「待核对」或两者。检查会匹配公共译文，排除明确的内部备注与未使用内容；待核对也可能是刻意保留的名称，不等于译源漏译。未下载的内容不计入统计，检查不使用 API 额度。

游戏设置为日语、英语或韩语时，都能使用所选汉化包。汉化覆盖按当前游戏语言统计，AI 补译也使用同一范围；切换游戏语言后会提示重新检查。

每个汉化包都按游戏语言保存覆盖报告。切回用过的包即可查看对应语言的上次结果，改名或换图标也会保留。包或游戏文本有变化时会提示重查，点右侧刷新图标即可更新报告。补译结束后会显示还剩哪些内容。

在「条目明细」中，选「未覆盖」查看缺少译文的内容，选「待核对」对照原文和已有译文。点「全部类别」可筛选剧情、战斗等内容。可勾选单条、多条，或选择「翻译全部已筛选条目」，再设置数量、密钥和提示词。AI 补译页也能直接按内容分类选择范围。点放大镜可搜索文字、游戏 ID 或 `#编号`。

生成、修改或删除部分译文后，可在 AI 页面查看上次改动的汉化包、时间、类别、条数和示例，再选择「撤回这次改动」，恢复之前的汉化和来源选择；已产生的 API 费用不退回。旧版记录仍可撤回，但没有条目明细。「测试翻译」会单独显示原文、译文和耗时，不会保存配置、切换汉化或改变游戏启动状态。

AI 页面提供「全局提示词」，内置按零协公开规范整理的文风参考，可以编辑、单独保存或恢复默认。有参考包时会提取命中译名和邻句；从零翻译使用内置规范。两种方式都检查数字与格式，AI 译文仍建议核对。[查看依据与质量说明](docs/ai-translation-quality.md)。

使用基于零协补译的 AI 包启动时，发现零协新版本会提示一次，你可以选择：

- **继续当前汉化**：不更新，直接使用已有包。
- **更新后只用零协**：加载新的正式译文。
- **更新零协，保留 AI**：同一条原文只要零协补齐，就使用零协译文。仍缺的沿用已有 AI 译文，不调用 API。
- **更新后继续补译**：先沿用可用译文，再按单批上限补译剩余内容。没有新的条目时，直接使用更新后的汉化，不调用 API。

同一个零协版本不会每次启动都询问，手动检查可重新选择。复用需要本机保留的 AI 生成缓存和原文校验；原文已变、缓存缺失的内容不会强行套用旧译文。旧 AI 包保留，可随时重新选择。

「恢复默认汉化」切回都市零协会，同时保留 AI 包；不再需要的 AI 包可单独删除，删除前会确认。

汉化内容取决于所选包的覆盖范围；尚未翻译的部分保留原文。BYBUS 自带字体，导入时只读取兼容的文本资源，不安装包内插件。

## 更新与维护

每次打开 BYBUS 首页会自动检查应用版本，有新版时显示红点。检查在后台进行，不影响游戏启动；服务器限流时按提示时间重试。

| 更新内容 | 操作入口 |
| --- | --- |
| BYBUS 应用本身 | 设置与工具 → 应用更新 |
| 原版游戏 | 设置与工具 → 游戏更新，按页面提示更新原版 |
| 汉化 | 设置与工具 → 汉化 → 汉化源与更新；零协自动跟进，自定义包可通过链接更新或手动替换 |

手动更新时，下载最新完整 APK **覆盖安装**即可保留数据；应用内更新不可用时也可采用此方式。卸载 BYBUS，或在手机系统设置里清除它的应用数据，会删除 BYBUS 内的游戏资源、本地登录信息和设置。

遇到汉化文件或字体加载异常，可打开「设置与工具 → 修复」。修复时会关闭游戏，保留账号和已下载的游戏资源，完成后从首页重新启动。

需要释放空间时，可使用 **BYBUS 内的「设置与工具 → 清除数据」**，确认后清理已下载的游戏资源与缓存。这个操作会保留账号，下次进入游戏需要重新下载资源。

<details>
<summary><strong>应用内增量更新是什么？</strong></summary>

应用内更新复用当前 APK 中未变化的内容，只下载需要补齐的部分，再交给系统安装。支持此方式的旧版本可直接更新，不依赖旧版发行文件；能节省多少流量取决于本次变化。

无法复用时会下载完整包，安装仍需足够的临时空间。**首次安装和手动更新始终下载完整 APK，无需寻找增量附件。**

</details>

各版本变化见[发行说明](https://github.com/gravere/BYBUS/releases)。Releases 保留最近三个正式构建的发行文件。

## 资源备份与迁移

在「**设置与工具 → 数据迁移**」中选择方向：

- **迁出**：把已下载的游戏资源保存为 ZIP，再传到另一台设备；本机数据保留。
- **迁入**：选择兼容资源 ZIP，补充缺少的文件，保留接收设备的已有资源。版本不同也可导入，由游戏补齐更新。

资源包不包含账号、Google 授权、应用设置或汉化源。新设备仍需安装原版游戏并登录账号；汉化包请在「汉化源与更新」中单独导出、导入。导出时会关闭游戏，操作前有确认提示。
