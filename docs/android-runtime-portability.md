# Android 设备适配

BYBUS 面向 Android 手机和平板。设备条件、游戏安装包与实际运行功能分别检查，
是否可启动由系统和游戏的实际条件决定。

## 设备条件

| 项目 | 条件 |
| --- | --- |
| 系统 | Android 8.0 及以上（API 26+） |
| 架构 | 64 位 ARM 系统与进程（arm64-v8a） |
| 内存页 | 4 KB 或 16 KB，按设备实际页大小检查原生库加载条件 |
| 游戏 | 设备上已安装官方《边狱巴士》，签名和原生结构通过检查 |

32 位系统、x86、Android 8.0 以下及未识别的内存页大小不在支持范围内。
相机、蓝牙、定位、麦克风、电话与 Wi-Fi 硬件为可选，手机和平板使用同一套基础检查。

## 游戏兼容性

游戏安装渠道不作为兼容性依据。BYBUS 检查官方签名、原生库布局、加载段对齐和
已识别的保护结构，并按对应游戏构建的规则判断是否可以启动。

已识别的同结构游戏更新可自动适配；未知保护结构、无法确认的安装包或加载条件
不满足时，会显示兼容提示。具体构建可以具有比基础设备条件更严格的要求。

## Google 账号与 16 KB 设备

Google 登录使用 BYBUS 容器内的独立账号环境。内置 Google 组件的部分 ARM64
原生库未满足 16 KB 对齐，16 KB 设备上的 Google 登录和付款兼容性尚未确认；
通过基础设备检查不代表这些功能可用。

## 窗口与布局

竖屏和正方形窗口使用单列。横屏在宽度和字体缩放满足可读空间时使用双列，
分屏按应用实际可用窗口调整。布局不依赖具体手机或平板型号。

## 运行与反馈

启动检查用于确认已知条件，不代表所有厂商 ROM、游戏页面、登录和付款流程均已
实测。可在应用内查看兼容报告和运行状态；遇到问题时，通过「设置与工具 → 导出诊断」
收集信息，并附上设备、系统、BYBUS 与游戏的实际版本提交反馈。

各次发行的具体验证范围见 [Release 说明](https://github.com/gravere/BYBUS/releases)。

依据：[Android 页大小指南](https://developer.android.com/guide/practices/page-sizes)。
