# 游戏更新后的启动检查

BYBUS 从 Android 读取当前安装的官方游戏及其拆分包。首次启动或游戏更新后，会核对包名、发行方签名、安装文件和本机加载必需原生库的条件。游戏在准备期间发生替换时，本次启动停止，下次启动重新读取安装信息。游戏数据保留。

新版本沿用有效的安装结构时，可以直接通过启动准备。BYBUS 无需事先登记游戏版本号。系统已安装的游戏通过系统包服务读取签名，手动导入的安装包还要逐份验证所有拆分包的签名、版本和依赖关系。

通过启动准备后，由游戏创建自己的 Application 并执行原有检查。游戏返回的安全提示可在本次运行记录中查看。汉化文件加载、进入游戏标题、看到中文是三个独立的验证结果。
