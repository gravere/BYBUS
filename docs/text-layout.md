# 已译文本的排版边界

按控件的有效高度、原始字号上限和显式换行区分标签与正文。较高正文框即使原本关闭
换行，也不能被改成单行标签；自动字号已经缩小后的当前值不应作为再次缩小的基准。
可换行正文启用换行并保留可读字号下限，不沿用过低的缩字下限或单行省略号。
单行标签保留原溢出方式，不由汉化层新增省略号。分页、关联文本、遮罩、专用滚动
和已核对的事件/播报协程继续由对应组件管理，不统一改变所有页面的高度和滚动行为。

可见字数和术语替换只将已识别的 TMP 富文本标签视为控制内容。台词中的尖括号是
可见文字，不能将 `<……>` 整段跳过；`noparse` 内按字面显示，并保留其中的原始标记。
这些规则不修改译文内容、游戏数据、账号或安全检查结果。组件复用后恢复原排版状态。

战斗/UI 文本的上下文在 `TextData_UI` 对象仍持有条目身份时处理。除了现有的实例
GetText 入口，也覆盖经完整签名、静态标志和代码空间核验的 `op_Implicit(TextData_UI)`；
该转换没有实例 this 参数，使用独立的一参数包装器。不能把同文异译的按钮统一替换成
出现次数最多的译名。只修改允许的显示字段，身份和其他元数据保持原值。
UI 加载器的两种确切 `SetText()` 入口在原函数调用期间按 `key` 传递线程内上下文，
用于转换被编译器内联后的兜底。只按条目身份、`content` 字段和完整原文同时匹配；
嵌套加载和返回时恢复前一上下文，不能将一个按钮的 key 留给下一个按钮。

技能层级文本使用 `@skill:技能ID/level:等级/coin:序号/text:序号` 上下文，只沿
已核对的 levelList、coinlist、coindescs 传递。等级按字段身份匹配，缺少身份的硬币和
说明数组只在原译两边等长且位置配对成立时生成。原生层从同一技能对象的字段与集合
方法取得对应层级；匹配仍要求字段名和完整日文同时一致，不把技能 ID 写入子对象。
`GetSkillTextByGaksungLevel(Int32)` 的完整签名核验后，在取得子对象前翻译整棵显示字段树，
避免子对象被单独使用后丢失技能身份。未知结构继续使用原有无歧义映射。

状态与战斗关键词表可复用相同 ID，但说明并不总相同。只对已经核对的
`TextData_Buf` / `TextData_BattleKeywords` 与对应资源族加上表类型；不以裸 ID
跨表选择译文。派生术语选定后，再核对每条完整记录的上下文，防止术语的默认
译名覆盖技能的正式名称。旧 Unity UI.Text 同样使用原始字号上限与可读下限，
避免按字数估算宽度把中文缩到 7 号；正文按有效高度换行。

E.G.O 饰品的 `simpleDesc` 是带 `abilityID` 的子对象列表。按饰品 ID 与能力 ID
共同配对，不能仅按数组位置选择另一条能力说明；只有重复记录两侧各自完全相同时
才能合并处理。原生层只沿 `TextData_EgoGift.simpleDesc` 到
`TextData_EgoGiftAbility` 传递身份，保留能力编号和其他非显示字段。

中文基准字体继续使用随包提供的 Sarasa Gothic SC Bold。TMP 的原始 fontStyle、
fontWeight 以及译源中的 b、i、u、color、size 标记保持原义；正文、条件小字与
技能标题的字号分别取对应控件，不统一覆盖为一个固定字号。材质转换保留原有
强调与选中状态；字形覆盖和模拟排版检查不代表已核验所有战斗画面的实际粗细。

检查使用真实发布资源的结构与针对上述边界的原生测试。完整剧情的页面布局需要实际
运行验证；离线匹配率不等同于所有场景已显示中文。
