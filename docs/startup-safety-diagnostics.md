# 启动安全提示与首次汉化诊断

启动阶段的安全提示可能在游戏进程退出时一并关闭。原诊断只记录 Intent 的字段名，
不能据此区分具体安全错误；进程收到 SIGKILL 也不能单独证明是哪项检查失败。

- 仅观察由已登记的游戏主进程发往自身 AppSealingAlertDialog 的 controller Intent。
  在转发前提取有明确编号标记的五位错误码、有限类型值和固定原因分类；不保存原始
  提示、reportFile 路径或内容、设备标识及其他 extras。不改变原 Intent、页面或终止行为。
- 结果与本次 launch.request 和调用进程 PID 绑定，写入宿主自己的小型诊断记录。
  运行状态优先显示本次安全提示，避免文本 hook 已加载被误读为游戏已正常运行。
- 完整汉化、启动页汉化、没有索引分别报告。诊断增加启动页索引状态、本次原文
  读取/配对数量和运行时回执；只导出有限状态值与计数，不导出原文或译文内容。
- APK 内五个已核对启动表与下载资源使用相同的逐条配对规则。某表不足 90% 时，
  已证实的记录仍可用于启动页；未配对文本保持原文。完整汉化的 90% 就绪门槛、
  原索引保留策略和未知 Unity 格式拒绝策略不变。

上述改动保留短暂提示并修复启动表部分配对被整表丢弃的问题，不代表已确定或修复
某台设备的安全检查失败。真实闪退原因仍需本次错误编号；不得根据系统版本或品牌
推测并关闭检查。测试限于来源约束、日志最小化、启动记录隔离和索引激活边界。
