# 本次发布说明

此文件只维护本次发布的更新内容。`scripts/prepare-release.py` 会从实际 APK 生成版本标题、下载链接与附件列表，写入发行输出目录的 `release-notes.md`；GitHub Release 使用生成的文件作为正文。

## 更新内容

- 首页内容与启动按钮整体居中，平衡上下留白，使用说明固定在底部。
- 更新面板固定显示下载进度、当前阶段和操作按钮，滚动更新说明时仍可查看。
- 启动和前台停留时自动检查 BYBUS 新版本，发现更新后显示红点，无需先手动检查。
- 自动提醒采用轻量更新描述，后台停止轮询；保留安装包校验、服务器限流等待与已有数据。
