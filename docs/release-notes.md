# 本次发布说明

此文件只维护本次发布的更新内容。`scripts/prepare-release.py` 会从实际 APK 生成版本标题、下载链接与附件列表，写入发行输出目录的 `release-notes.md`；GitHub Release 使用生成的文件作为正文。

## 更新内容

- 修复首次安装 Google 组件后，账号服务尚未识别组件、需要重启才能继续登录的问题。
- 修复容器安装服务中断时启动检查一直等待的问题；超时后的后台安装继续受保护。
- 账号配置改为完整写入后原子替换，避免写入中断覆盖已有登录记录。
- 翻译项目遵守 ParaTranz 的限流等待时间，重启应用后仍保留等待状态。
- 修复底层同地址函数重复拦截、ARM64 指令偏移计算及信号上下文判断，减少部分设备的启动崩溃风险。
