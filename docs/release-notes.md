# 本次发布说明

此文件只维护本次发布的更新内容。`scripts/prepare-release.py` 会从实际 APK 生成版本标题、下载链接与附件列表，写入发行输出目录的 `release-notes.md`；GitHub Release 使用生成的文件作为正文。

## 更新内容

- 启动阶段直接融入主按钮与分段环形进度，移除按钮上方的小字，保持页面布局稳定。
- 游戏同步等操作完成后，按钮短暂显示勾选与完成状态，替代浮出的成功提示；可直接继续启动游戏。
- 完成反馈适配深色模式、放大字体与系统无障碍提示时长。
- 设置中加入统一的数据迁移入口；旧版先保留数据并覆盖更新一次，之后在新版发起迁移。
- 支持导入 limbusZhCN 及兼容容器导出的资源 ZIP，保留已有文件，允许不同资源版本。
