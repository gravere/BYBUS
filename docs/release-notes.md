# BYBUS v1.0.10

**首次安装或手动更新，请下载完整 APK：**

[下载 BYBUS v1.0.10 · Android ARM64 完整安装包](https://github.com/gravere/BYBUS/releases/download/v1.0.10-build.53/BYBUS-v1.0.10-arm64-v8a.apk)

## 更新内容

- 平板竖屏改为单列，启动、安装信息和汉化项目状态从上到下排列，使用同一页面滚动。横屏在空间足够时保留双列，分屏和大字体按实际可用窗口调整。
- 修复汉化初始化依赖固定原生库磁盘路径的问题，改用游戏实际加载的模块句柄，逐项核验接口归属，适应 APK 内加载和路径差异。
- 改用 Unity 主线程判断来准备中文字体。后台线程及尚未就绪的字体设置不会耗尽重试机会；创建失败可有限重试，复用已创建的字体，避免首次失败导致整次启动停留在原文。
- 运行状态区分索引、文本接管和字体初始化，字体未就绪或失败时给出对应说明。

## 如何更新

v1.0.7—v1.0.9 可在应用内下载匹配的差异补丁；首次安装、其他旧版或手动更新请使用上方完整 APK。覆盖安装保留游戏资源、登录和设置，不要卸载旧版。

首次使用请先登录并完成游戏资源下载，再返回 BYBUS 启动一次以启用完整汉化。容器内 Google 账号与系统 Play 商店独立，新设备需重新登录。

## 附件怎么选

| 文件 | 用途 |
| --- | --- |
| `BYBUS-v1.0.10-arm64-v8a.apk` | 完整安装包，首次安装和手动更新选择此文件 |
| `BYBUS.apk` | 同一完整包的自动更新兼容名称，不必重复下载 |
| `BYBUS-update-52-to-53.delta` | v1.0.9 到本版的差异补丁，由应用自动处理 |
| `BYBUS-update-51-to-53.delta` | v1.0.8 到本版的差异补丁，由应用自动处理 |
| `BYBUS-update-50-to-53.delta` | v1.0.7 到本版的差异补丁，由应用自动处理 |
| `bybus-update.json`、`SHA256SUMS.txt` | 更新元数据与校验值，不是安装包 |
| GitHub 的 Source code 文件 | 项目源码，不是安装包 |

`.delta` 不能独立安装。增量更新减少下载量，合成与覆盖安装仍需完整 APK 的临时空间。发行文件保留最近三个正式构建。

## 兼容性与验证范围

支持范围仍为 Android 8.0 及以上的 64 位 ARM 手机和平板，游戏须通过官方签名和原生结构校验。32 位系统、x86、Android 8.0 以下及未识别的游戏保护结构仍不支持。

内置 Google 组件仍有部分 4 KB 原生库，其 16 KB 登录与付款兼容性尚未确认。本次更新未改动账号及计费流程。

本版针对窗口布局、首次资源准备、运行状态、模块解析和字体重试执行定向本地回归，并校验正式构建、签名和差异更新。没有连接手机或平板；本次报告设备的汉化失败尚未获得运行日志复现，实际显示与厂商 ROM 兼容性仍待用户更新后验证。
