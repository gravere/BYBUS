# 本次发布说明

此文件只维护本次发布的更新内容、验证范围和兼容说明。`scripts/prepare-release.py` 会从实际 APK 生成版本标题、下载链接与附件列表，写入发行输出目录的 `release-notes.md`；GitHub Release 使用生成的文件作为正文。

## 更新内容

- 平板竖屏改为单列，启动、安装信息和汉化项目状态从上到下排列，使用同一页面滚动。横屏在空间足够时保留双列，分屏和大字体按实际可用窗口调整。
- 修复汉化初始化依赖固定原生库磁盘路径的问题，改用游戏实际加载的模块句柄，逐项核验接口归属，适应 APK 内加载和路径差异。
- 改用 Unity 主线程判断来准备中文字体。后台线程及尚未就绪的字体设置不会耗尽重试机会；创建失败可有限重试，复用已创建的字体，避免首次失败导致整次启动停留在原文。
- 运行状态区分索引、文本接管和字体初始化，字体未就绪或失败时给出对应说明。

## 兼容性与验证范围

支持范围仍为 Android 8.0 及以上的 64 位 ARM 手机和平板，游戏须通过官方签名和原生结构校验。32 位系统、x86、Android 8.0 以下及未识别的游戏保护结构仍不支持。

内置 Google 组件仍有部分 4 KB 原生库，其 16 KB 登录与付款兼容性尚未确认。本次更新未改动账号及计费流程。

本版针对窗口布局、首次资源准备、运行状态、模块解析和字体重试执行定向本地回归，并校验正式构建、签名和差异更新。没有连接手机或平板；本次报告设备的汉化失败尚未获得运行日志复现，实际显示与厂商 ROM 兼容性仍待用户更新后验证。
