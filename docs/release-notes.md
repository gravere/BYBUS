# BYBUS v1.0.7

**首次安装或手动更新，请下载完整 APK：**

[下载 BYBUS v1.0.7 · Android ARM64 完整安装包](https://github.com/gravere/BYBUS/releases/download/v1.0.7-build.50/BYBUS-v1.0.7-arm64-v8a.apk)

## 更新内容

- 修复新设备 Google 登录流程中的调用方识别和添加账号页面返回链路，统一用于手机和平板。
- 增加独立的启动页汉化准备：资源下载前，使用当前游戏包中可验证的启动、登录与提示原文配对零协译文；完整索引仍保留资源就绪校验。
- 完整汉化优先使用已有索引；启动页索引单独保存、校验和清理，不覆盖已有完整汉化。

## 如何更新

v1.0.5、v1.0.6 可在应用内下载匹配的差异补丁；首次安装、旧版或手动更新请使用上方完整 APK。覆盖安装保留游戏资源、登录和设置，不要卸载旧版。

首次使用请先登录并完成游戏资源下载，再返回 BYBUS 启动一次以启用完整汉化。容器内 Google 账号与系统 Play 商店独立，新设备需重新登录。

## 兼容性与验证范围

本版修复不按品牌或型号分支。当前游戏运行支持范围仍为 **Android 16 / arm64 / 4 KB 内存页**，且游戏安装包须通过原生兼容检查；尚不支持所有 Android 版本或 16 KB 运行环境。

已进行相关本地回归、正式构建、签名与更新包校验。未连接平板或手机，Google 实际网络登录、平板画面及当前游戏资源包中的启动文本覆盖率尚未实测；不能据此宣称所有设备均已验证。
