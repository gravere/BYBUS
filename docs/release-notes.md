# 本次发布说明

此文件只维护本次发布的更新内容。`scripts/prepare-release.py` 会从实际 APK 生成版本标题、下载链接与附件列表，写入发行输出目录的 `release-notes.md`；GitHub Release 使用生成的文件作为正文。

## 更新内容

- 启动按钮移到运行状态与项目卡片之间，上下卡片向页面两端舒展，减少外侧留白。
- 启动按钮加入轻柔的渐变水波纹圈层；打开菜单或切到后台时停止动画。
- 更新页分为 BYBUS 与汉化资源两个标签，版本信息更清楚，进度和操作固定在底部。
- 本地汉化改用中英翻译图标；横屏布局为中间启动区域预留空间，并根据字体大小自动调整。
- 二级面板适配系统手势条与三键导航，统一底部背景，并让操作按钮避开系统导航区域。
